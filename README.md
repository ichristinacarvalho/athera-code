# 🌌 Athera Code

> Website institucional e portfólio digital focado em desenvolvimento web moderno, interfaces interativas e soluções digitais criativas.

---

## 🚀 Sobre o Projeto
O **Athera Code** é o ponto central de apresentação de projetos, marca e competências técnicas em desenvolvimento front-end e design web. O projeto foi idealizado para entregar uma navegação fluida, visual marcante e arquitetura de código limpa, aplicando boas práticas de estilização, layout responsivo e interatividade.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica e acessível das seções da página.
* **CSS3:** Estilização moderna, animações suaves, layout flexível e responsividade.
* **JavaScript (ES6+):** Lógica interativa, manipulação do DOM e componentes dinâmicos.
* **Git & GitHub:** Controle de versão e hospedagem do código.
* **Firebase (Firestore / Realtime Database)**: Backend-as-a-Service utilizado para gerenciar e salvar os dados do formulário de contato.

---

## ⚙️ Funcionalidades
* **Apresentação de Serviços e Portfólio:** Destaque para projetos desenvolvidos e soluções técnicas.
* **Design Responsivo:** Adaptado para proporcionar uma excelente experiência em dispositivos móveis, tablets e desktops.
* **Componentes Interativos:** Elementos visuais dinâmicos para engajamento do visitante.
* **Seção de Contato/Links:** Acesso facilitado para redes sociais e canais de comunicação.
